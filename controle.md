# Curso de Git & GitHub

Curso introdutório de versionamento de código com Git e GitHub, dividido em 21 aulas
organizadas em quatro módulos: **Fundamentos**, **GitHub**, **Colaboração** e **Projeto final**.

## Agrupamentos

| Módulo | Aulas | Foco |
|---|---|---|
| 1 · Fundamentos do Git | 1–7 | Versionamento local: do primeiro repositório ao histórico e ao desfazer erros. |
| 2 · GitHub & repositórios remotos | 8–12 | Levar o projeto para a nuvem: publicar, clonar e organizar o trabalho com Issues. |
| 3 · Branches, colaboração e Pull Requests | 13–20 | Trabalho em equipe: branches, Pull Requests, revisão, merge, conflitos e fork. |
| 4 · Projeto final | 21 | Fluxo completo de colaboração em grupo, do primeiro commit ao merge. |
